---
title: Keyboard shortcuts
---

Every command has default shortcuts that you can change in **Settings → Keybinds** or in `config.toml`; press `F1` in Luciole to see the current ones.

## Customize shortcuts

Shortcuts live in `[browser.keybinds]`. Each key is a command id and holds up to four chords; an empty array unassigns the command, and omitted commands keep their defaults. Changes apply to open windows immediately.

```toml
[browser.keybinds]
search = ["Ctrl+F", "Ctrl+K"]
open_in_new_tab = ["Ctrl+Return"]
open_in_other_pane = ["Ctrl+Alt+Return"]
open_in_new_window = ["Shift+Return"]
administrator_access = ["Alt+Shift+Return"]
copy_target_path = ["Ctrl+Alt+C"]
copy_target_uri = ["Ctrl+Alt+U"]
zoom_in = ["Ctrl+equal", "Ctrl+plus", "Ctrl+Shift+plus", "Ctrl+KP_Add"]
quick_preview = []
```

Commands belong to one of three scopes, listed below. Two commands in the same scope cannot share a chord, and Settings refuses the conflict; the same chord may be used once in each scope. `Super` combinations belong to the compositor and are rejected. While browsing, Tabs and Windows bindings take precedence over File Browser bindings; for example, `F6` switches areas.

:::caution
An unknown command id or malformed chord in `[browser.keybinds]` invalidates the whole file, unlike other unknown keys. Check the reported error before restarting.
:::

Chords use key names such as `Return`, `Escape`, `Tab`, `space`, `BackSpace`, `Delete`, `Menu`, `Home`, `End`, `Page_Up`, `Page_Down`, `equal`, `minus`, `plus`, `comma`, `KP_Add`, `KP_0` and function keys such as `F4`. `Next` and `Prior` are aliases for `Page_Down` and `Page_Up`, and `Ctrl+,` and `Ctrl++` are accepted for `Ctrl+comma` and `Ctrl+plus`. Printable keys need `Ctrl`, `Alt` or another modifier; `Shift` alone is not enough, except for `validate` and `quick_preview`.

:::note
If another File Browser command already uses `Ctrl+Alt+C`, `Ctrl+Alt+U`, `Ctrl+Alt+Return` or `Shift+Return`, the corresponding newer default stays unassigned until you assign it. The same applies to Administrator Access if `Alt+Shift+Return` is already assigned.
:::

The archive viewer follows `cancel`, `focus_next`, `focus_previous`, `move_up`, `move_down`, `move_first`, `move_last`, `move_page_up`, `move_page_down`, `select_all`, `parent_folder`, `up` and `open`. `quit` works everywhere, including with a menu open. `select_tab_9` always selects the last tab, and every `Escape` handler also follows `cancel`.
