Copy, move, create and rename files, and watch running jobs in the File Operations popover.

## Copy and move

Select items, press `Ctrl+C` to copy or `Ctrl+X` to cut, open the destination folder and press `Ctrl+V`. Paste is also in the context menus, including List view. Clipboard transfers and drag and drop work between Luciole windows and with other applications.

When copying or moving to removable storage, File Operations shows **Writing to device…** while the filesystem finishes writing. Wait for completion before ejecting the drive. If writing fails after a file appears in the destination, the report marks the transfer partial and lists any retained replacement.

To copy paths as text, use **Copy Location**: **Path** (`Ctrl+Alt+C`) or **URI** (`Ctrl+Alt+U`). Several items are separated by newlines. To change these shortcuts, see [keybinds](/luciole/keybinds/).

## Paste an image

If the clipboard holds an image (PNG, JPEG, WebP, GIF, BMP, TIFF or SVG), `Ctrl+V` asks for a name, default `Pasted image`, and saves a new file in the current folder. An existing name is reported, never overwritten. The folder needs a native path, which includes mounted SFTP and WebDAV folders. You can undo it, see [undo and redo](/luciole/undo-redo/).

## Drag and drop

Drop files on a folder, or anywhere in the destination pane to use the folder shown. Dropping on a file uses its folder.

| Modifier | Result |
|---|---|
| `Ctrl` | Copy |
| `Shift` | Move |
| `Alt` | Opens an action menu at the pointer |
| none | Follows **Settings → General → When Dropping Files**: **Ask What to Do** (default), **Copy Here** or **Move Here** |

The menu offers **Create Link Here** for native folders and within one mounted SFTP server. These are symbolic links, not copies. Cross-server links and SMB or WebDAV links are unavailable, see [network folders](/luciole/network/).

With exactly one supported archive dropped on a native folder, **Extract Here** extracts into a new folder named after the archive. **Move into New Folder…** asks for a name, creates the folder and moves the files into it; the folder stays if the move fails. Dragging a folder into Places pins it. Dropping on Trash is covered in [trash](/luciole/trash/).

## Drop from an archive application

Entries dragged from a compatible archive application are copied once the source has prepared the files. Luciole waits up to two minutes for the list.

Some applications instead ask Luciole to extract into a local folder. They handle passwords, progress and name conflicts, and Luciole only reports that extraction was requested. Keep the source open; review or cancel there. These extractions do not appear in File Operations or undo history.

## Resolve name conflicts

When names collide, the dialog offers **Replace**, **Skip** and a numbered new name. Folder copies can merge into existing folders. Apply-to-all choices last for the current job, and retrying failed items is explicit. Cancel stops the remaining work; finished items stay done.

:::caution
**Replace** permanently discards the previous item, including a folder's contents. Undo cannot bring it back.
:::

## Create items

The folder background menu offers **New Folder** (`Ctrl+Shift+N`) and **New Document**, which has an empty file (`Ctrl+Alt+N`) and the files in your XDG Templates folder.

**Create Link** on one native item makes a symbolic or hard link where supported. **Show Link Target** on a symbolic link opens the folder holding its target and selects it; use it again to follow a chain.

## Rename

Press `F2` to rename one item. With several native items from one folder selected, it opens batch rename; check the preview before applying.

Choose **Regex** to replace every match of an ECMAScript regular expression. In **Replace**, `$1`, `$2` insert captured groups, `$&` the whole match and `$$` a dollar sign. With **Keep extensions** on, find `^IMG_(\d+)$` and replace with `Photo-$1` to turn `IMG_0042.jpg` into `Photo-0042.jpg`.

- Non-matching names stay unchanged.
- Matching is case-sensitive and works on bytes, so `.` can match part of a multibyte character.
- `\1` back-references in **Find** are not supported.
- A new name that is not valid UTF-8 is flagged and cannot be applied.

## File Operations popover

The toolbar **File Operations** button shows the number of active jobs. Open it, or use **File Operations** in the main menu, to see every tab and window of this Luciole: progress, bytes, item totals, pending decisions and results. Jobs cannot be paused.

- **Cancel** stops remaining work; finished effects remain. Closing the popover does not cancel.
- **Review** returns to the page waiting for your decision.
- **Details** shows a report; **Copy Report** copies it.
- **Retry Failed** appears while retry information lasts and skips finished items.
- **Clear Finished** drops results; the latest 12 are kept until then or until you quit.

The popover closes when the window is resized.
