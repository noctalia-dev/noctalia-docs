---
title: Programs and custom scripts
description: Run custom scripts and programs on selected files in Luciole.
---

Add your own executable scripts to the context menu to act on the selected files.

## Install a script

1. Choose **Scripts → Open Scripts Folder** from a file or folder background menu. It opens, or creates, `$XDG_DATA_HOME/luciole/scripts/`, which is `~/.local/share/luciole/scripts/` by default.
2. Place your executable script there.
3. Reopen the **Scripts** submenu to see it.

Hidden files, non-executable files, `.desktop` launchers and nested script folders are not listed.

## Write a script

A script receives the selected native paths as separate arguments. Its working directory is the folder shown in the pane it was started from. From the background menu it receives no paths.

For example, forward the selection to an editor:

```sh
#!/bin/sh
exec my-editor "$@"
```

Replace `my-editor` with your program. Keep `"$@"` quoted so names with spaces stay single arguments. Luciole never builds a shell command from file names. Interpreters and commands must exist on your system.

## Safety rules

The scripts folder, its `luciole` parent and each executable target must be owned by you or root, and not writable by group or others. Symbolic links to qualifying targets work, including read-only declarative scripts. Luciole never makes an unsafe folder writable for you.

:::caution
Scripts are arbitrary programs you install and run, not sandboxed extensions.
:::

## Limits

- The menu shows at most 64 scripts and inspects at most 1024 entries.
- One launch accepts at most 4096 selected paths and 1 MiB of path arguments.
- Scripts need a native folder and native selected items outside Trash.
