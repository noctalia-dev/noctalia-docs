---
title: File picker
---

Luciole can provide the Open and Save dialogs of applications that use the FileChooser portal.

After choosing files or closing a picker, the requesting application becomes available again and any parent-window dimming ends.

Install Luciole and `xdg-desktop-portal`, then select the `luciole` backend as described below. Keep your desktop's other portal backends for screen sharing, screenshots and other interfaces. This choice is separate from the default file manager; applications with their own dialogs keep them.

If you use [xdg-desktop-portal-umbriel](https://github.com/noctalia-dev/xdg-desktop-portal-umbriel), its configuration already prefers Luciole when installed, with GTK as the fallback. No override is needed unless another configuration takes precedence.

## File picker on other distributions

Install your distribution's `xdg-desktop-portal` package alongside Luciole. The installation must include `share/xdg-desktop-portal/portals/luciole.portal` and its D-Bus service; an uninstalled development binary does not register the picker.

Check your desktop name:

```sh
echo "$XDG_CURRENT_DESKTOP"
```

Find the desktop's portal configuration in `/usr/share/xdg-desktop-portal/` or `/etc/xdg/xdg-desktop-portal/`; source installations may use `/usr/local/share/xdg-desktop-portal/`. GNOME uses `gnome-portals.conf` and KDE uses `kde-portals.conf`. Names use the lowercase desktop name; a colon-separated value supplies several names, checked in order.

Copy that file into `~/.config/xdg-desktop-portal/`, keeping its filename and preferences. If a user configuration already exists there, edit it instead. Use `$XDG_CONFIG_HOME/xdg-desktop-portal/` if you set another configuration root.

Under its existing `[preferred]` section, add or replace only the FileChooser entry:

```ini
[preferred]
org.freedesktop.impl.portal.FileChooser=luciole;gtk
```

Merge this entry into the copied file; do not replace the file, and keep its `default` and other interface preferences. The `gtk` fallback needs `xdg-desktop-portal-gtk`. You can omit it or use another installed backend such as `kde`.

If your session supplies no portal configuration, create `~/.config/xdg-desktop-portal/portals.conf`. With `xdg-desktop-portal-gtk` installed, this is a minimal starting point:

```ini
[preferred]
default=gtk
org.freedesktop.impl.portal.FileChooser=luciole;gtk
```

Configure compositor-specific interfaces, such as screen sharing, through their own backend. Portal configuration files are selected as a whole; a new file does not inherit preferences from lower-priority files. See the upstream [configuration search rules](https://flatpak.github.io/xdg-desktop-portal/docs/portals.conf.html).

## File picker on NixOS

Register Luciole through `xdg.portal.extraPortals` in your **NixOS system configuration**, including when Home Manager or hjem installs Luciole. `nix run` alone does not register the backend.

For a session without a portal configuration, this example supplies GTK for other interfaces and Luciole for file picking:

```nix
{ inputs, pkgs, ... }:
{
  xdg.portal = {
    enable = true;
    extraPortals = [
      inputs.luciole.packages.${pkgs.stdenv.hostPlatform.system}.default
      pkgs.xdg-desktop-portal-gtk
    ];
    config.common = {
      default = [ "gtk" ];
      "org.freedesktop.impl.portal.FileChooser" = [ "luciole" "gtk" ];
    };
  };
}
```

Use the [flake input and argument setup](/luciole/installation/#add-the-flake-input). If you already configure portals, add Luciole to `extraPortals` and add the FileChooser preference to your session's configuration, keeping its other preferences and backend packages. For a managed GNOME configuration use `xdg.portal.config.gnome."org.freedesktop.impl.portal.FileChooser" = [ "luciole" "gtk" ];`. For KDE use `config.kde` with `[ "luciole" "kde" ]`. Keep the desktop's `default` and interface entries.

`config.common` generates the generic `portals.conf`; it is not merged into desktop-specific files. A matching desktop-specific file in the same directory takes precedence, and a generic file can shadow a packaged desktop configuration in a lower-priority directory. Files in `~/.config/xdg-desktop-portal/` can also override the NixOS configuration. See the [NixOS portal options](https://github.com/NixOS/nixpkgs/blob/master/nixos/modules/config/xdg/portal.nix).

Rebuild your system, then apply the session steps below. Luciole's modules do not select the file picker automatically.

## Apply and check the file picker

Log out and back in after installing and configuring, or restart the portal frontend in a systemd session:

```sh
systemctl --user restart xdg-desktop-portal.service
```

Restart the requesting application, then try its Open or Save dialog. The application must use the FileChooser portal, and it may need its own portal preference.

The chooser has its own [view, hidden-file and preview settings](/luciole/configuration/#browser-preferences). Its windows use the Wayland app ID `dev.noctalia.luciole-chooser`, with a hidden desktop entry that reuses Luciole's icon, so compositor rules can target them without affecting ordinary windows.

Network folders opened through GVfs, such as `smb://` or `sftp://`, can be chosen while GVfs's FUSE daemon (`gvfsd-fuse`) runs; applications receive their path under `/run/user/<uid>/gvfs/`. Without it, the picker refuses them.

If the old picker still appears, check the configuration's filename and precedence, Luciole's installed portal file and the application's portal support. With systemd, inspect errors using:

```sh
journalctl --user -b -u xdg-desktop-portal.service
```

:::note
The fallback list covers an absent backend. It does not guarantee fallback when an installed backend fails to start or returns an error.
:::
